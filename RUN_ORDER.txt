DATA245 IoT — SIX EASY PYTHON SCRIPTS
==================================
From the extracted project folder, run:

  python -m pip install -r requirements.txt

  python src/01_eda_preprocessing.py        # Read CSV, dedupe, EDA, splits
  python src/02_train_models.py             # Train Decision Tree and kNN
  python src/03_model_evaluation.py         # Accuracy, precision, recall, F1, confusion
  python src/04_classification_errors.py    # Where are the models making mistakes?
  python src/05_repeated_split_experiments.py  # Repeat experiment 10 times
  python src/make_presentation_charts.py    # Plot figures for slides

Or run everything:

  python src/run_all.py --include-repeated

Fastest method to just show figures (saved results already included):

  python src/make_presentation_charts.py

Verification:

  python tests/check_saved_outputs.py
